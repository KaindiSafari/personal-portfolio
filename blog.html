How I Deployed My First Website to AWS S3

February 2026 | AWS, S3, CloudFront

Today I deployed my personal portfolio website to AWS S3 for the first time. Here's what I learned and the challenges I faced...

The Challenge: I wanted to host my portfolio website without paying for a server and AWS S3's static website hosting was the perfect solution.

What I Did:

  • Created an S3 bucket with a globally unique name
  • Configured the bucket for static website hosting
  • Set up bucket policies to make content publicly accessible
  • Uploaded my HTML, CSS, and assets
  • Tested the website using the S3 endpoint

Key Learnings: Understanding bucket policies was crucial. I learned about AWS IAM policies and how to properly configure public access while maintaining security best practices.

Next Steps: I plan to add CloudFront for faster content delivery and set up a custom domain with Route 53.
